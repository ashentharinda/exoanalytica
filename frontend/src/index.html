Automated exoplanet detection & light curve analysis

From citizen scientist to researcher: analyse NASA Kepler and TESS data in minutes. ExoAnalytica finds the transits, checks them for false positives, and estimates each planet's size and temperature.

Get started free See how it works

What it does

Direct NASA access

Fetch Kepler and TESS light curves from the MAST archive by target ID (TIC, KIC or EPIC), or upload your own CSV or FITS file.

CNN transit scoring

A convolutional neural network scores every signal, and each individual transit, so you can see which events to trust.

False-positive checks

Odd/even depths, secondary eclipses, transit shape, duration and instrumental glitches are checked to flag eclipsing binaries and noise.

Multi-planet search

Finds up to five separate signals per star by hiding each one in turn, and reports radius, temperature and habitable-zone position.

How it works

  1. Bring a light curve. Upload a file or type a target ID such as TIC 261136679.
  2. We search and vet. The data is cleaned, searched for repeating dips, scored and checked.
  3. You get a verdict. Charts, a table of planet parameters, and a CSV or printable report.
