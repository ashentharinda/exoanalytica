# RV Dataset Source Register

## Primary source: ESO HARPS RV Catalogue

URL: https://archive.eso.org/scienceportal/

Purpose:
- Study real HARPS radial velocity measurements.
- Identify suitable targets for a pilot dataset.
- Examine observation cadence and measurement uncertainties.

Reference:
ESO HARPS Radial Velocities Catalogue, first public data release,
12 December 2023. DOI: 10.18727/archive/33.

## Primary source: NASA Exoplanet Archive

URL: https://exoplanetarchive.ipac.caltech.edu/

RV resources:
https://exoplanetarchive.ipac.caltech.edu/docs/rv.html

Purpose:
- Obtain published RV time series.
- Identify known planetary systems.
- Cross-check target and planet reference information.

## Secondary source: HARPS RVBank

URL: https://www2.mpia-hd.mpg.de/homes/trifonov/HARPS_RVBank.html

Purpose:

- Compare target coverage and data formats.

## Acquisition rules

1. Do not overwrite original source files.
2. Record source identifiers and download dates.
3. Preserve original units and timestamps.
4. Record time standards and instrument identifiers.
5. Do not mix instruments without modelling offsets.
6. Check access conditions and citation requirements.
7. Validate each dataset before using it.
8. Keep known-signal validation separate from blind testing.
